# Random Quote Generator

**Автор:** Краснов Александр Андреевич

## Описание

Random Quote Generator — это графическое приложение на Python, которое генерирует случайные цитаты из предопределённого списка или добавленных пользователем. Приложение сохраняет историю сгенерированных цитат и позволяет фильтровать их по автору и теме.

### Основные возможности

- ✅ Генерация случайной цитаты из списка
- ✅ Отображение текста цитаты, автора и темы
- ✅ Сохранение всех сгенерированных цитат в историю (с временной меткой)
- ✅ Фильтрация истории по автору и по теме
- ✅ Добавление новых цитат через диалоговое окно
- ✅ Автоматическая проверка ввода (запрет пустых полей)
- ✅ Сохранение цитат и истории в JSON-файлы
- ✅ Удобный графический интерфейс (tkinter)

### Технологии

- Python 3.7+
- Tkinter (встроенный GUI)
- JSON для хранения данных
- Random для выбора случайных цитат
